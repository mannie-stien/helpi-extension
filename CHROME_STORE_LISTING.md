## Detailed Description (16,000 characters max)

### Main Description

Helpi is an intelligent AI assistant that provides instant, context-aware help for any content on the web. Whether you're reading articles, coding, analyzing data, or viewing charts, Helpi understands what you need and offers the right actions.

🎯 **CONTEXT-AWARE INTELLIGENCE**
Helpi automatically detects what you've selected and shows relevant actions:
• Code → Explain, Improve, Debug
• SQL Queries → Optimize, Explain
• Math Equations → Solve, Show Steps
• JSON/YAML/XML → Parse, Validate
• Images & Charts → Describe, Analyze
• Regular Expressions → Explain Pattern
• Foreign Text → Translate
• Questions → Answer with Context
• Technical Terms → Define, Give Examples
• Long Paragraphs → Summarize, Key Points

🤖 **MULTI-PROVIDER AI SUPPORT**

## FAQ for Store Listing

**Q: Is Helpi free?**
A: Yes, Helpi is free to install. You'll need an API key from an AI provider (Together.ai, OpenAI, Anthropic, or Google AI). Most providers offer free tiers.

**Q: Which AI provider should I use?**
A: Together.ai offers great free tier. OpenAI has GPT-4. Anthropic has Claude 3. Try different providers for different tasks!

**Q: Does Helpi work offline?**
A: No, Helpi requires internet connection to communicate with AI providers.

**Q: Is my data private?**
A: Yes! API keys are stored locally. No tracking or analytics. Direct API calls to providers.

**Q: Can I use it on any website?**
A: Yes! Helpi works on all websites.

**Q: What makes Helpi different from ChatGPT extensions?**
A: Helpi detects context automatically (13+ types), analyzes visual content, supports multiple AI providers, and has conversation memory.
